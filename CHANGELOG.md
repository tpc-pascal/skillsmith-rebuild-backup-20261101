# Changelog

All notable changes to this repository are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and versions follow [Semantic Versioning](https://semver.org/): every release is a `vX.Y.Z` tag whose GitHub Release notes are taken from the matching section below.

### Added

- Optional session-fetched `watch` integration for video summaries in the media workflow.
- Optional session-fetched `agent-reach` channels for web and social reading.
- Research request orchestrator with a report-requirements question gate.
- Local-first document extraction and conversion guidance for PDF, DOCX, and XLSX.
- Local media processing guidance for video, audio, images, and URLs.
- Public web and social-source reading guidance with explicit external-service disclosure.
- Research report-writing guidance with evidence, citation, export, and verification references.
- SemVer release automation that publishes GitHub Release notes from the matching changelog section.
- Initial research collection scaffold, including the collection guide, installer, and session-fetch helper.
- Automated upstream license synchronization through review pull requests.
- Automated upstream pin checks and review pull requests for changed revisions.
